# University Admission Portal Website

This project was developed as part of my Information Technology and Computing (ITC) course. The objective of the project was to design a simple and user-friendly university admission portal inspired by the SZABIST admission system.

## My Role
My primary contribution to this project was developing the HTML structure of the website. I worked on organizing the layout and different sections of the portal. I was also introduced to basic CSS and JavaScript concepts and prepared parts of the project for presentation.

## What I Learned
Working on this project helped me understand how front-end technologies come together in a real-world system. It strengthened my understanding of webpage structure, teamwork, and the importance of planning in web development.

- HTML  
- CSS
